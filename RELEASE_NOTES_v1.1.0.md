# BLACK SHEEP TOWN English v1.1.0

This release makes Steam Build 13300478 the source authority while retaining
support for the original Japanese Windows retail release. The Steam script was
aligned, translated, and subjected to a complete 106-packet semantic audit
before both runtime projections were built from the same finalized manuscript.

## Included

- Complete English game script for Steam Build 13300478
- Steam-authoritative English projection for the original Japanese retail build
- Complete localized Tips encyclopedia for each build
- English system text
- Repaired English page wrapping using the original message-window layouts
- Windows and macOS/Wine install, verification, and restoration helpers
- Complete Japanese/English browser with 29,753 visible rows across 63 scenarios
- Canonical 29,754-row editorial corpus and source-provenance receipts

## Verification

The archive was installed, reinstalled, verified, restored, deliberately
corrupted, and transactionally rolled back against temporary copies of both
supported Japanese data files. Every reconstructed and restored hash matched
exactly. The validation performed zero game launches.

## Install

Download and extract `BLACK_SHEEP_TOWN_English_v1.1.0.zip`, then follow the
