# BLACK SHEEP TOWN English v1.2.3

Fixes the missing entries in “All Tips” reported with v1.2.2.

The earlier Tips cleanup removed reading values that the game also uses to
index entries. This update restores those values for all 211 Tips. Japanese
readings appear beside English titles again; English titles and descriptions
are unchanged. Story text, chapter titles, typesetting, and unlock conditions
are preserved.

## Updating

Restore Japanese with your previous patch package first, then install v1.2.3.
Use the v1.2.3 Restore helper before downgrading. The installer does not modify
save files. Steam Build 13300478 only; Japanese retail remains unsupported.

## Verification

All 211 index values match the original Steam source. Only the Tips object
changes from v1.2.2. Archive integrity, clean installation, repeat installation,
exact restoration, restore-then-upgrade from v1.2.2, mixed-state rejection,
and transactional rollback passed. In-game visual verification of the title
and game menus remains incomplete.
